**课题**: 社交媒体圈层用户引导策略与效果预测——针对不同社交媒体圈层特性,构建精准引导策略模型,量化预测策略对圈层舆论及用户行为的影响效果。

**Why(用户的战略思考)**: 用户已经把课题拆成三层建模框架,并识别出这不是纯回归而是**反事实/What-if 模拟**问题——这决定了模型必须是**模拟器(simulator)结构**而不是**预测器(predictor)结构**。

**How to apply**: 后续所有技术讨论都应该锚定这三层的分工:
1. **圈层识别层**:基于用户互动构造转发图,用 Leiden 划分圈层 → 详见 [[project-algorithm-decisions]]
2. **传播预测层**:给定议题+圈层结构+初始状态+策略A → 预测传播效果、效果增量、风险
3. **策略优化层**:通过遍历/搜索不同策略,评估 ROI(效果/成本)

**评价指标层次**:
- 传播效果本身(分圈层热度曲线、圈层激活时间顺序、情绪演化、话题词漂移)
- 相对基线(不介入)的增量
- 风险(失控概率、逆火效应)

**策略量化维度(用户已梳理)**:
- 传播主体(种子节点选择)
- 内容形式(情绪、话题词)
- 圈层维度(在哪圈层激活、是否搭桥连通)
- 时机(早/晚介入)
- 强度(资源投入)

**反事实验证要求**: 必须包含 historical strategy validation(大V下场事件) + placebo test + 敏感度分析中的至少两条,评委会问。

**数据结构**: 三批数据(重大议题8个/热点事件263个/传播案例114个),原始为帖子级 CSV(GB18030 编码),已索引为 Parquet。字段和实况详见 [[project-data-reality]]。
