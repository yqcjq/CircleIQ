### 0.2 被推翻/降级的（含推翻理由）

| 原结论 | 判决 | 理由 |
|---|---|---|
| **"时机>咖位"**（低潮期 Δ+320 ≫ 爆发期 ≈0） | **推翻（效果侧）** | 线性 Hawkes 叠加性 ⇒ 注入事件的期望增量 Δ = 该通道期望簇大小，**与背景状态/注入时刻严格无关**。观测差异是伪影：爆发期近临界模拟撞 `_simulate_one` 的 500,000 事件 cap（case_study.py:80），两臂同时截断把 Δ 压成 0；低潮期不撞 cap，Δ=簇大小（+320 ⇔ 分支比≈0.997，高方差估计）。**时机的真实角色在风险侧**：失控概率依赖当前状态，爆发期注入更易过阈值 |
| **"单帖大V神话的量化否定"** | **降级为 scoped 表述** | 通道聚合模型 by construction 无法表达帖级咖位（2 亿粉与普通号的帖是同一维度的同一种事件）。只能写"通道级注入的期望增量=分支比量级"，不能写"咖位不重要" |
| **策略网格 = 搜索发现** | **重构** | 线性性 ⇒ 期望 ROI = 簇大小−1，与注入量 m 无关、与延迟无关；溢出构成 = (I−N)⁻¹ 的闭式代数。网格中 m×delay 轴的差异全是 MC 噪声+cap 截断。"圈注入高ROI低溢出 vs 散户大总量全溢出"结论不假，但它是 α 矩阵的代数推论，且继承 α 全部误差（近临界放大 1/(1−n̄) ≈ 20×+） |
| **"GRU 锚定 μ 修复反事实可信度"**（2026-07-29 上午 Claude 提议） | **撤回主要主张** | Δ 不依赖 μ，校准基线不改变效果增量。锚定仅对报告总量与失控阈值有用，降为可选项 |
| **placebo（注入无关圈 Δ≈0）** | **砍掉** | 闭式下是恒等式，零信息 |
| **验证三件套的"评委会"依据** | 依据作废，重排 | 新核心检查 = α 可辨识性/扰动稳健性（因 Δ=f(α) 且近临界放大误差）+ 历史案例定量化（唯一触及现实的检验） |

### 0.3 已坐实的待修复缺陷

1. **筛选面板 partition 泄漏**：`experiments/pred_screen/build_dataset.py:36` 用全量 `partition_stable_K3.parquet`，圈成员身份部分由 test 期互动定义。服务器有现成 `partition_stable_K3_pre.parquet`（仅 2025-07-01 前互动），对照重跑成本低。
2. **strategy_optimizer 的 `delta_other_share` 只算散户维**，标注为溢出但不含 bigv/org 溢出。
3. **成本不可比**：ROI 把"大V 发一帖"与"散户发一帖"当同价，跨通道 ROI 比较无意义。

### 0.4 赛题覆盖度缺口（从赛题文本逐句核对）

- "量化预测策略对圈层**舆论**…的影响"：舆论（情绪/观点构成）目前**零模型**。情绪列在热点事件/传播案例近 100% 填充（AI就业+生育话题部分变体缺失）——数据支持最好却完全没做的一句。
- "解析…**信息偏好**"：目前只有内容一致性和激活谱，缺每类圈层的行业/情绪/媒体类型偏好谱（描述统计即可，字段填充率支持）。
- "差异化引导策略**体系**"：有逐事件网格，缺"圈层类型 → 打法"的组织层。
- "**融合**机器学习与智能模拟"：两半都有（GRU/GBDT vs Hawkes），融合点需明确为角色分工（预测器出基线/触发时机识别，模拟器出增量/风险），并在论文里与被否掉的"点预测混合"划清界限。

## 1. 任务分解

### P0-1 反事实通道的数学重构（闭式 Δ）——半天到 1 天

- 实现闭式期望增量：注入通道 d 的期望簇大小 = `1ᵀ(I−Nᵀ)⁻¹ e_d`（N 由 A1/A2 与 β 积分得到）；溢出构成 = 对应列的维度分解。对全部 313 个已拟合事件一次性计算（纯线代，秒级）。
- 与现有模拟结果对照：亚临界事件上两者应在 MC 误差内一致（正确性验收）；近临界事件上标记 cap 截断污染的旧数字。
- **复检 case_study 四事件**：用闭式 Δ 重算，验证"+320 vs ≈0"的伪影解释；更新 stage-cde 报告的 §4 表述。
- 敏感度主检查：α 元素 ±20% 扰动（或 bootstrap 重拟合）下，per-事件通道排序的 Kendall τ；报告近临界放大效应。
- 产出：`docs/strategy-validity-audit.md` + 修订 stage-cde-report.md 相关段落。

### P0-2 预测大规模验证 + 泄漏审计——1~2 天

- 圈范围从 {0,5} 扩到全部 ≥100 人的 top 圈（builder 已支持 counts[6,nb] 扩展）；GRU/GBDT/naive 三模型，双视界，分层报告，按事件 bootstrap。
- **`_pre` 防泄漏 partition 对照跑**：结论不变则记录，变了则如实报告并以 _pre 为准。
- 顺带产出"圈层激活判别"（y>0 的 AUC）作为独立指标，零额外成本。

### P0-3 策略层重构——2 天

- **闭式 Δ 替代网格**：全部可信事件（热点+案例，剔大议题）× 全通道，效果/溢出用闭式，模拟只算失控概率。
- **按圈层类型池化** → "类型 × 通道 × 内容情绪"打法表：五类圈层各自的最优注入通道、情绪敏感度、风险特征；疑似组织化圈（圈26/圈2）列为**监测对象而非引导对象**（潜在风险的直接回应）。
- **内容情绪维**：按情绪分组参数（愤怒/中性/喜悦组的 A、β）做情绪条件下的闭式 Δ 与失控模拟——策略的"内容形式"维度落地。
- **时机重新定位**：效果侧时机无关（0.2 的推论，如实写）；风险侧时机敏感（不同锚点状态下的失控概率曲线)——"介入时机决定风险而非收益"作为修正后的策略结论。
- **成本处理**：不做跨通道 ROI 排序；按通道分别报告 Δ/风险，附成本参数敏感度说明。
- 修复 `delta_other_share` 口径（溢出分解到全部非目标维）。
- 产出：重构版策略章节 + 每类型"效果-风险"图。

### P0-4 验证（重排后）——1~2 天

- **α 稳健性**（核心）：跨事件池化稳定性（已有）+ 半窗重拟合一致性 + 扰动下排序稳定性（并入 P0-1）。
- **历史案例定量化**：选 N 个有真实权威账号中途下场的事件，比对模型闭式 Δ 的方向/量级与实际再加速；替代原"方向性校验"。
- ~~placebo~~ 已砍（闭式下恒等式）。

### P1-1 舆论线（补赛题缺口）——1~1.5 天

- 圈层-情绪构成演化：**马尔可夫链基线**（圈层×情绪状态转移，可解释）起步；有余力再加 GRU 情绪份额头（softmax 输出）复刻"基线 vs 序列模型"对比。
- 策略→舆论指标：注入内容情绪经传播后的圈内情绪构成偏移（接 P0-3 的情绪条件 Δ）。

### P1-2 信息偏好画像——半天

- 每类型圈层的 行业/情绪/媒体类型/发帖时段 偏好谱（描述统计，100% 填充字段），补赛题"信息偏好"一词。
