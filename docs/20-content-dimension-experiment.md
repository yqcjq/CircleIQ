# 内容维度实验报告:路径 A + 路径 B 完整对比

**创建**: 2026-07-26
**状态**: 已实施,三方案实测完成
**数据**: 婚俗改革议题前 3 csv(94,122 独立用户,37,022 图内用户,49,778 边)
**执行环境**: RTX 4090 24GB / 24 vCPU / Python 3.10

---

## 1. 实验目的

用户在完成 Leiden POC 后提出:"最初评估标准没加内容相似度,现在觉得应该加"。为此对比三种方案:

- **Leiden**:仅用图结构(baseline,前 POC 已跑通)
- **Hierarchical**(路径 B 类别 1):Leiden 顶层保留 + 大圈内部按内容 embedding 细分
- **GNN**(路径 B 类别 3a):GraphSAGE 无监督,BGE 内容作节点特征,图结构做消息传递

## 2. 实验设计

### 2.1 数据管线

```
hunsu_first3.parquet (358,212 帖, 94,122 独立用户)
    ↓ [B1] BGE-small-zh (GPU 4090)
user_text_emb.parquet (94,122 × 512)
    ↓
    ├─→ [B2] 路径 A: 圈内一致性评估 → content_consistency.csv
    ├─→ [B3] 路径 B 类别1: Leiden + 内容子分 → partition_hierarchical.parquet
    └─→ [B4] 路径 B 类别3a: GraphSAGE + HDBSCAN → partition_gnn.parquet
                ↓
       [B5] 三方案综合对比 → path_ab_comparison.csv
```

### 2.2 关键实施细节

**B1 用户级 embedding**:
- 每用户拼接前 5 条帖子的 title + content_full,单帖截断 500 字
- BGE-small-zh-v1.5 编码为 512 维,normalize
- GPU 编码 3-4 分钟,GPU 利用率 73%

**B3 Hierarchical**:
- 对 size >= 200 的 Leiden 圈(21 个)内部做 KMeans
- 子圈数 = 用户数 / 300,范围 [2, 20]
- 共 517 原子圈 → 605 层次化圈层,93% 用户被细分覆盖

**B4 GraphSAGE**:
- 输入:BGE 512 维作节点特征,edges.parquet 作图
- 网络:2 层 SAGE,隐藏 128,输出 64,L2 normalize
- 训练:20 epoch,batch 4096,负采样 5,4090 GPU 每 epoch ~0.1 秒
- 输出向量做 HDBSCAN (min_cluster_size=50)

## 3. 实验结果

### 3.1 综合对比表(含 GNN 参数调优)

**主表**:

| 方案 | 社区数 | Modularity | 内容一致性 (weighted) | vs Leiden ARI | 有效覆盖 |
|---|---|---|---|---|---|
| **Leiden** | 517 | **0.752** | 0.614 | — | 37,022 (100%) |
| **Hierarchical** | 606 | 0.227 | **0.728** | 0.206 | 37,022 (100%) |
| **GNN(原版 out=64)** | 156 | 0.085 | 0.867 | 0.295 | 13,433 (36%) |

**GNN 调优 3 组(2026-07-26 追加)**:

| 配置 | Modularity | 内容一致性 | ARI vs Leiden | 备注 |
|---|---|---|---|---|
| A: 3层 hid=256 out=128 neg=10 | 0.031 | 0.891 | 0.19 | 增加容量,更差 |
| B: BGE + 6维struct 拼接(518d) | 0.013 | 0.877 | 0.12 | 结构信号被淹没 |
| C: BGE降PCA到64d + 4层 out=64 | 0.019 | 0.888 | 0.13 | PCA没帮助 |

**GNN 调优结论**: 三组调参**全部使结构信号更差**(Modularity 0.013-0.031 vs 原版 0.085)——因为增加模型容量或改变输入维度,模型都倾向于用来记住内容而非结构。这证明 **GraphSAGE + 对比学习目标**本身不适合本任务,不是调参问题。

### 3.2 路径 A(内容一致性)详细分布

在 Leiden 划分基础上,对 size >= 20 的 42 个圈计算圈内平均余弦相似度:

**全局指标**:
- 随机采样对的相似度基线:**0.491**
- Leiden 圈内平均(加权):**0.583**
- Leiden 圈内平均(未加权):**0.643**
- 圈内相似度显著高于随机基线(+18%),说明 Leiden 圈**存在一定内容一致性**

**分布**:
- avg_cosine > 0.7(内容一致): 10 个圈 (23.8%)
- 0.5-0.7(中等): 26 个圈 (61.9%)
- < 0.5(散乱): 6 个圈 (14.3%)

**头部大圈偏低**:
- CID=0 (7281 用户): 0.493(接近随机基线,内容极散)
- CID=1 (5337 用户): 0.553
- CID=2 (3545 用户): 0.524
- CID=6 (1572 用户): 0.710(相对纯净)

**含义**: Leiden 头部超大圈内部混合了多个话题子群,是**路径 B 类别 1(层次化细分)的正当理由**。

### 3.3 路径 B 类别 1(Hierarchical)结果

**层次化圈层**:
- 21 个大圈被细分,产生 105 个子圈
- 顶层 Leiden 保持不变(517 个),叠加子分后共 605 个层次标签

**指标解读**:
- 内容一致性从 0.614 → 0.728(**+18.6%**)
- Modularity 从 0.752 → 0.227(**-70%**)

**原因**: 细分把 Leiden 原本紧密的大圈拆散,内容近的用户分到一起,但很多有互动的用户被拆到不同子圈,结构模块度大幅下降。

### 3.4 路径 B 类别 3a(GNN)结果

**GraphSAGE 训练(原版)**:
- 20 个 epoch,损失从 1.35 收敛到 0.94
- GPU 4090 训练时间 <3 秒
- HDBSCAN 聚类 187 秒(单核瓶颈)

**指标解读**:
- 内容一致性最高:0.867
- Modularity 崩溃:0.085
- **71% 用户被 HDBSCAN 标为噪声**——只有 29% 用户被有效分组

**问题分析**:
- GraphSAGE 用 BGE 512 维作节点特征,图结构只提供邻居聚合
- BGE 内容信号太强,图结构信号被淹没
- 最终 embedding 更像"内容 embedding + 少量结构调制",几乎不反映社群
- 需要调整训练:降低内容特征维度,或增加图结构的权重(如更多层 GNN),但已超出 POC 范围

### 3.5 GNN 参数调优三组对比(2026-07-26 追加)

针对"GNN 结构崩溃"问题,尝试三组调参配置,期望找到"结构+内容"的更优平衡点:

**Config A(增加容量)**:
- 3 层 SAGE + 隐藏维度 256 + 输出维度 128 + 负采样 10 + 25 epoch
- 期望:更深的消息传递让结构信号扩散更远
- 实测:Modularity 从 0.085 → **0.031**(变差),内容一致性 0.87 → **0.89**(略升)

**Config B(结构特征显式拼接)**:
- 输入 = BGE(512) + 6 维图结构统计(度、PageRank、聚类系数、coreness、连通性、平均邻居度)= 518 维
- 期望:显式让 GNN 看到结构信号
- 实测:Modularity **0.013**(所有 GNN 版本最差),内容一致性 0.88
- 6 维结构特征在 512 维 BGE 里被完全稀释

**Config C(内容降维)**:
- BGE 512 → PCA 降到 64 维 + 4 层 SAGE + 30 epoch
- 期望:降低内容比重让图结构占比更均衡
- 实测:Modularity 0.019(仍很差),内容一致性 0.89
- PCA 保留了内容主方差,反而让下游 HDBSCAN 更容易按内容聚类

**三组调参的一致教训**:

**给 GNN 更多表达能力,它更倾向于用来记住内容而非结构**。原因:
1. GraphSAGE + 对比学习(直连节点向量相近)的目标很弱
2. BGE 内容信号在直连节点之间本来就相近,梯度早期就消耗殆尽
3. 图结构信号是"稀疏离散"的,而内容信号是"稠密连续"的,模型偏好稠密特征
4. 无论加维度、加层数、加结构特征拼接、还是降维内容,都改变不了这个偏好

**结论**:GraphSAGE + 无监督对比学习不适合本任务,不是调参问题,是**方法结构问题**。可能有效的替代:
- **DGI**(Deep Graph Infomax):目标是"节点向量对齐全局图摘要",强制利用结构
- **BGRL**(Bootstrap Your Own Latent for Graphs):自举学习,避免负采样退化
- **监督学习**:用 Leiden 结果作为监督标签训练 GNN

**当前 POC 不再尝试这些方案**,因为:
- 主线 Leiden + Hierarchical 已足够
- 论文里可以用"GraphSAGE 三种调参均无法平衡"证明"我们主线选择是理性的"

## 4. 关键发现

### 4.1 结构和内容存在真实 trade-off

三方案的 Modularity 和内容一致性呈现明显的负相关:

```
Leiden       : mod=0.75, content=0.61  ← 结构强,内容中
Hierarchical : mod=0.23, content=0.73  ← 中间
GNN          : mod=0.09, content=0.87  ← 内容强,结构崩
```

**这不是算法缺陷,是数据本身的性质**:在这个议题下,**"有互动的人"和"讨论内容相似的人"确实不完全重合**。

**验证**:三方案两两 ARI 都在 0.21-0.29,说明它们看到的**不是同一个东西**——是三个不同的"圈层观"。

### 4.2 Leiden 头部大圈的内容散乱是真问题

Leiden 前 3 大圈(占 45% 用户)的圈内相似度都 <0.55,接近随机基线。这提示:

- 圈内成员来自多个内容子群
- 单纯的关系互动没能把内容相近的人聚在一起
- **策略层如果针对"CID=0"下场,实际是在影响多个不同兴趣的子群体**

### 4.3 简单融合的天花板

Hierarchical 和 GNN 都是"结构 + 内容"的融合,但**没有成为两全其美的方案**——都在结构和内容之间做出了牺牲。

**这告诉我们**:
- 没有"银弹"融合方法能同时达到 Leiden 的 Modularity 和 GNN 的内容一致性
- 需要根据**下游应用**选方案,而不是追求单一指标最优

## 5. 三方案的适用场景(策略层视角)

**Leiden 主导 - 互动引导策略**:
- 目标:通过转发链传播信号
- 用户群:CID 定义的社群
- 优势:圈内互动密度高,信号扩散快
- 应用:大 V 下场、内容注入的传播模型
- **对应本课题中的传播预测层**

**Hierarchical 主导 - 内容 + 位置分层策略**:
- 目标:先定位内容相关人群,再基于结构筛选
- 用户群:大圈内的内容子圈
- 优势:内容一致性提升,策略语义更精确
- 应用:定向内容投放、议题级情绪管理
- **可作为传播预测中的"内容维度先验"**

**GNN 主导 - 纯内容策略**:
- 目标:找讨论主题最相近的人群
- 优势:内容一致性最高
- 劣势:结构信息丢失,71% 用户漏掉
- 应用:纯内容营销、议题相关性分析(非本课题主线)

## 6. 对总体方案的影响

### 6.1 主线圈层算法保留 Leiden

数据说明 Leiden 的 Modularity 优势非常显著(0.75 vs 其他 <0.25),**结构维度是圈层的基础语义**。在竞赛的"引导策略"框架里,策略的作用机制是"通过传播影响用户"——这**必须依赖真实互动关系**,不能被内容代替。

### 6.2 引入 Hierarchical 作为增强层

对 Leiden 头部大圈**建议做后处理细分**,理由:
- 头部圈内容散乱是真问题(0.49 vs 基线 0.49)
- Hierarchical 已实证能提升内容一致性(+18.6%)
- 实施成本极低(已跑通)

**具体做法**:在原分层圈层框架的 Layer 1(Leiden 原子圈)后,对 size >= 200 的圈做 BGE 内容子分,得到"L{super_id}.C{sub_id}"两级 ID。

**对论文的价值**: 可以呈现"通过内容维度精细化圈层"的完整对比实验,而不是单一算法选择。

### 6.3 GNN 作为论文对比方法

GNN 作为主算法不适合(结构信号弱、覆盖低),但可以作为**论文的对比方法**放在附录:
- 展示"GNN 试图同时优化结构+内容,但实际做不到"
- 证明主线选 Leiden(+ 可选 Hierarchical)是理性选择
- 加分:说明我们对比了 SOTA 方法后做的选择

- **阶段 A** 保持:多话题 Leiden + 元圈层
- **阶段 A 增强**:每话题的 Leiden 结果加一步 Hierarchical 细分(小工作量,大收益)
- **阶段 B**(本文档所述实验)**已完成**

## 8. 论文写作提示

论文里可以增加一节"内容维度的必要性验证":

> 为验证是否需要将内容相似度作为圈层划分的评估维度,我们设计了三方案对比实验:纯图结构(Leiden)、层次化(Leiden + 内容细分)、图神经网络融合(GraphSAGE)。
>
> 结果表明:
> 1. Leiden 圈内内容相似度显著高于随机基线(0.61 vs 0.49),证明关系网络本身与内容具有一定相关性
> 2. 但头部大圈的内容一致性显著偏低(0.49-0.55),表明纯图算法在超大圈上存在"内容散乱"问题
> 3. 通过对头部大圈进行 BGE embedding 后处理细分,内容一致性提升 18.6%,而对整体结构 modularity 影响可控
> 4. GraphSAGE 试图同时融合结构与内容,但导致图结构信号被淹没(modularity 0.08),验证了简单融合方案不适合本任务
>
> 综合评估结果,我们的圈层识别采用"Leiden(主线)+ 头部圈层内容细分(增强)"的两级架构,兼顾传播分析所需的结构完整性与策略定向所需的内容一致性。
