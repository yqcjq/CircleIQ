## 算力踩坑与修正(当日)

1. **polars + fork 死锁**: 主进程用过 polars 后 fork 的子进程卡死(CPU time=0)→ 全部 ProcessPoolExecutor 换 spawn context
2. **run_hawkes 线程超订**: 8 worker × polars 默认 24 线程 → load 127,吞吐反降 → `POLARS_MAX_THREADS=3`
3. **csv 字段超 128KB**: `csv.field_size_limit(sys.maxsize)`
4. **pandas 3.0 to_datetime 返回 ms 单位**: 显式 `astype('datetime64[s]')` 再转 int64
5. **数值列脏浮点超 int64**: `to_numeric` 后夹取 `|x|<2^62`
6. **超临界分支比模拟爆炸**: 模拟器加 max_events 上限,命中率本身作为失控信号

## 关键现场决策(与依据)

- **本地预处理、只上传 core**: 带宽 2.3MB/s 决定(317GiB 原始不可能上云;core:text=1:16)
- **稳定圈计数范围扩到 382 单元**: 跨议题用户 Jaccard≈0.01,靠 263 个热点事件放大配对观测
- **Hawkes 维度混合通道**: 热点事件中稳定圈事件占比仅 1-17%,纯圈维度会让 other 吞 83-99% 质量
- **β 固定网格+每维凸 MLE**: 换取凸性/收敛保证与跨事件可比,代价是单一时间尺度(局限已记录)
