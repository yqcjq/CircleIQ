# docs/ 文档管理规范

## 文档体系

| 文件 | 职责 |
|---|---|
| README.md（本文件） | 文档命名规范 + 更新流程 |
| 00-INDEX.md | 阶段编号定义 + 全文件索引（含每个文件的内容摘要） |

## 文档命名规范

### 文件命名

格式：`{阶段编号}{序号}-{英文短名}.md`

规则：
- **第一位数字** = 所属阶段（阶段定义见 `00-INDEX.md`）
- **第二位** = 该阶段内的序号，按文档创建顺序递增：0–9，满后续大写字母 A–Z（每组最多 36 个）
- **英文名** = kebab-case，简明描述文档主题
- 示例：`11-stage-a-report.md` = 阶段 1（圈层识别）的第 2 个文件

### 图片命名

格式：`{引用文档编号}-{描述}.png`

规则：
- 编号取引用该图片的文档编号（两位数字）
- 描述部分用下划线连接，简明说明图片内容
- 若被多个文档引用，编号之间用 `+` 连接：如 `11+12-k_grid.png`
- 未被引用的图片，按内容归属到最相关的文档编号

### 归档文件

不再有效的文件（被取代、未推进、纯日志等）移入 `archive/` 子目录，不编号，保留原文件名。

## 文档更新流程

### 新建文档

1. 确定所属阶段 → 查 `00-INDEX.md` 中该阶段当前最大序号 → 取下一个序号
2. 创建文件，命名遵循上述规范
3. 在 `00-INDEX.md` 对应分组下追加索引行（格式：编号 | 文件名 | 做了什么 | 方法 | 结论）
4. 若包含图片，图片放入 `figures/`，以文档编号开头命名

### 归档文档

1. 将文件 `git mv` 到 `archive/`
2. 从 `00-INDEX.md` 正文索引中移除
3. 在 `00-INDEX.md` 的 archive 区追加一行（文件名 | 被谁取代 | 原因）

### 新增阶段

1. 在 `00-INDEX.md` 顶部的阶段定义表中追加新行，分配下一个可用数字
2. 在索引正文中增加对应分组标题
