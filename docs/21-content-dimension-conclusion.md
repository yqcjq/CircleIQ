## 一、动机溯源

**问题起点**:Leiden POC 完成后,用户提出——最初评估标准里没有"内容相似度",这个缺失是否需要补上?

**两个可能的路径**:
- **路径 A**:把内容作为**评估指标**(不改主算法) —— 补充一个维度看 Leiden 的圈是否内容一致
- **路径 B**:把内容作为**算法输入**(改主算法) —— 让内容参与圈层划分,期望更好

**目标**:两个都做,用数据说话。

## 二、执行了什么

**数据**:婚俗改革议题前 3 csv,94,122 独立用户(37,022 在图中),49,778 条互动边

**技术栈**:
- BGE-small-zh-v1.5 编码用户文本 embedding(512 维,GPU 编码 4 分钟)
- 路径 A:计算每个 Leiden 圈的圈内平均余弦相似度
- 路径 B:实现 4 种方案(Hierarchical + GNN 原版 + GNN 3 组调参)

## 三、路径 A(内容作为评估指标)的结论

### 3.1 数据

| 参照 | 平均余弦相似度 |
|---|---|
| 随机采样对(baseline) | 0.491 |
| Leiden 圈内平均(加权) | **0.583** |
| Leiden 圈内平均(未加权) | 0.643 |

**Leiden 圈内相似度显著高于随机基线**(+18%),证明关系互动与内容确实相关。

### 3.2 但分层差异极大

按圈大小分层看:

| 圈类型 | 相似度 | 含义 |
|---|---|---|
| **头部大圈**(size >= 3000) | 0.49-0.55 | **几乎等于随机基线** |
| 中型圈(size 1000-3000) | 0.55-0.71 | 有一定内容相关性 |
| 小型圈(size 100-1000) | 0.60-0.80+ | 内容相对一致 |

**头部大圈是"多话题子群大杂烩"**:
- CID=0(7281 用户):0.493 —— 完全随机
- CID=1(5337 用户):0.553
- CID=2(3545 用户):0.524

**中小圈相对纯净**:
- CID=6(1572 用户):0.710
- CID=7(1561 用户):0.692

### 3.3 分布统计

- avg_cosine > 0.7(内容一致):10 圈 (23.8%)
- 0.5-0.7(中等):26 圈 (61.9%)
- < 0.5(散乱):6 圈 (14.3%)

### 3.4 路径 A 的核心结论

- Leiden 圈的内容一致性**不是"没有"而是"分层"**
- 圈越大内容越散乱(混合多个话题子群)
- 圈越小内容越纯净(往往是明确的兴趣小群体)
- **说明"有互动"倾向于但不保证"内容相似"**

## 四、路径 B(内容作为算法输入)的结论

### 4.1 完整六方案对比表

| 方案 | Modularity | 内容一致性 | ARI vs Leiden | 覆盖率 |
|---|---|---|---|---|
| **Leiden**(baseline,纯图) | **0.752** | 0.614 | — | 图内 100% |
| **Hierarchical**(Leiden顶层+大圈内容子分) | 0.227 | **0.728** | 0.21 | 100% |
| GNN 原版(BGE+SAGE 2层) | 0.085 | 0.867 | 0.29 | 36% |
| GNN-A(3 层 hid=256 out=128) | 0.031 | 0.891 | 0.19 | 36% |
| GNN-B(BGE+结构统计特征拼接) | 0.013 | 0.877 | 0.12 | 39% |
| GNN-C(BGE PCA 到 64d + 4 层) | 0.019 | 0.888 | 0.13 | 36% |

### 4.2 两个关键发现

**发现 1:结构和内容存在真实 trade-off**
- 越强调结构 → Modularity 越高,内容一致性越低
- 越强调内容 → 内容一致性越高,Modularity 越低
- 无法同时达到"Leiden 的 Modularity + GNN 的内容一致性"

**发现 2:GNN 三组不同方向的调参全部失败**
- Config A 增加模型容量 → Modularity 更差(0.031)
- Config B 拼接结构统计特征 → 最差(0.013)
- Config C 降维内容 → 无改善(0.019)
- **一致规律**:给 GNN 更多容量,它总是用来记住内容而非结构

**为什么 GNN 一定会往内容偏**:
1. BGE 512 维内容 embedding 信息量大且稠密
2. 图结构信号稀疏离散(边关系),梯度弱
3. GraphSAGE + 对比学习目标(直连节点向量相近)在内容已经相近的情况下梯度早期就消耗掉
4. 无论怎么调参,神经网络会先学"简单的强信号"(内容),没剩下容量学"复杂的弱信号"(结构)

**这不是调参问题,是方法结构问题**。可能有效但未尝试的替代:
- DGI(Deep Graph Infomax)——目标是"节点向量对齐全局图摘要"
- BGRL(自举学习)——避免负采样退化
- 监督式 GNN——用 Leiden 结果作为监督标签

### 4.3 Hierarchical 方案(路径 B 类别 1)的独特价值

在三种路径 B 方案里,**Hierarchical 是唯一"两全部分"的方案**:
- 顶层保留 Leiden(517 圈)——结构信号还在
- 头部大圈(21 个,size >= 200)按 BGE 内容 KMeans 子分
- 得到 605 层次化圈层,93% 用户被覆盖到子分层
- 内容一致性从 0.61 提升到 0.73(+18.6%)
- 只在被细分的大圈内牺牲了 Modularity

**为什么它是路径 B 里最合理的方案**:
- 不试图用一个算法同时优化两个矛盾目标
- 分层处理:顶层用结构信号,细分用内容信号
- 保留 Leiden 的可解释性和结构完整性
- 只在真正需要的地方(头部大圈)加内容

## 五、最终技术选型

**主线**:
1. **Leiden**(策略作用域定义,Modularity 0.75)
   - 用于圈层的顶层划分
   - 保证策略作用域是"有互动关系的一群人"
   - 传播预测层的通道基础
2. **Hierarchical**(策略精细定位,内容一致性 0.73)
   - 对头部大圈(size >= 200)按内容 KMeans 子分
   - 得"L{super_id}.C{sub_id}"两级标签
   - 覆盖 100% 用户,论文可讲"层次化圈层"

**辅助**:
- **内容一致性指标**(路径 A)入论文作评估维度
- GNN 三组调参失败作论文对比章节,证明主线选择的理性

**弃用**:
- GNN(所有版本)作主算法
- 试图用单一算法同时优化"结构+内容"

## 六、论文写作素材

### 6.1 "圈层识别"章节结构

**6.1.1 引言**:圈层可以从三个维度定义
- 结构维度(有互动关系)
- 内容维度(讨论相似话题)
- 画像维度(相似身份属性)

**6.1.2 选型依据**:课题是"传播引导策略"
- 引导机制通过转发链传播 → 必须依赖真实互动关系
- **主线选结构维度(Leiden)**
- 内容和画像作评估维度

**6.1.3 主线算法**:Leiden + Hierarchical
- Leiden 单话题 517 圈,模块度 0.752,稳定性 100%
- Hierarchical 对头部大圈做内容子分,覆盖 100%,内容一致性 0.728
- 层次化圈层结构,策略层可用

**6.1.4 对比方法**(展示技术方法论完整性)
- profile_kmeans(纯画像)—— ARI vs Leiden = 0.04,证明**结构与画像正交**
- GNN(纯图神经网络)—— 三组调参失败,证明**简单融合不适合**
- 内容一致性评估 —— Leiden 圈内 0.583 vs 随机 0.491,证明**结构与内容部分相关**

**6.1.5 结论**:
- 圈层的结构维度独立于画像和内容
- 主线方法保留结构完整性,通过分层处理引入内容精细化
- 层次化圈层为传播预测层提供合理的圈层粒度

### 6.2 具体可写的段落

**关于结构与画像的正交性**:
> 我们对比了 Leiden 与基于画像特征(地域、行业、认证等级、粉丝量、发帖数)的 K-means 划分。两者的调整兰德指数(ARI)仅为 0.04,证明基于关系的圈层结构与基于画像的分组几乎完全独立。这意味着"因互动形成的社群"与"同地域/同身份的一批人"是**根本不同的东西**——策略引导应针对前者,因为传播机制依赖真实互动。

**关于内容维度的评估**:
> 为验证 Leiden 圈层的内容一致性,我们用中文 SBERT (BGE-small-zh-v1.5) 对每个用户的文本 embedding 到 512 维,计算圈内平均余弦相似度。结果:圈内平均相似度为 0.583(加权),显著高于随机对基线 0.491(+18%),证明关系互动与内容存在正相关。然而头部大圈(用户 >3000)的圈内相似度仅 0.49-0.55,接近随机水平,说明超大圈内混合了多个话题子群。这一发现驱动了我们的层次化圈层设计。

**关于 GNN 融合失败**:
> 我们尝试用 GraphSAGE 融合结构与内容信号,通过三组不同参数配置(增加模型容量、拼接结构统计特征、降低内容维度)探索平衡点。实验证明**三种调参方向均使结构模块度下降到 0.013-0.031**(vs 原版 0.085 和 Leiden 0.752),内容一致性维持在 0.87-0.89 但用户覆盖率仅 30%。分析表明,这不是调参不当,而是 GraphSAGE + 对比学习目标本身**偏好稠密内容信号**,无论如何调参,神经网络容量都会先被用来记住内容。这一发现证实结构与内容是**两个根本不同的信号**,支持了我们选择分层处理而非单一融合的方案。

**关于 Hierarchical 的合理性**:
> 我们的最终方案采用两级层次化圈层:顶层用 Leiden 划分保留结构信号(517 圈,Modularity 0.752),对头部大圈(21 个,size ≥ 200)在其内部用内容 embedding K-means 子分,得到 605 个层次化圈层。内容一致性从 0.614 提升至 0.728(+18.6%),同时保留了顶层的结构完整性。这种分层设计既满足策略引导对"互动关系"的需求(顶层),也满足对"话题精细化"的需求(子层)。
