# 舆论线:圈层情绪构成的预测与技术选择(2026-08-04)

**目标**: 补齐赛题"量化预测策略对圈层**舆论**及用户行为的影响效果"中此前零建模的
"舆论"半句——预测圈在事件中未来 24h 的**情绪构成**(6 维份额),并给策略层提供
"注入内容情绪 → 圈内情绪偏移"的量化接口。
**代码**: `experiments/pred_full/sentiment_line.py`(复用 pred_full 面板的通道×情绪×小时张量)。
**结论先行**: 情绪构成的可预测结构**主要在事件层,不在圈层的时间演化里**——
"事件历史构成"基线(0.527 L1)大幅赢"圈自身持续"(0.674),两者 0.7/0.3 混合最优(0.540/
命中率 0.777);GRU 序列模型只赢持续基线、追不上事件基线;马尔可夫转移链**输给持续基线**,
"情绪状态演化"的建模方向被数据否决。策略含义:**改变圈内情绪构成的杠杆是改变事件内容
构成本身,而不是在时间轴上"引导"情绪转移**。

---

## 1. 任务定义

- **样本**: pred_full 面板中 y24≥5 的锚点(份额在小计数下无意义),12,886 个
  (train 10,245 / test 2,047),事件切分与预测线完全一致
- **目标**: 圈 c 在 (t, t+24h] 的 6 维情绪份额(中性/愤怒/惊奇/喜悦/悲伤/恐惧,
  +1 伪计数平滑)
- **指标**: L1 距离(=2×总变差)、KL、主导情绪命中率;按事件 bootstrap ×400 对比持续基线
- 数据前提:情绪列在热点/案例近 100% 填充(04 号报告);转发与根帖情绪一致率仅 76.6%
  (愤怒 87.6%,恐惧 48.8%)——情绪列不是纯标注继承,含真实变异,预测任务成立

## 2. 结果

![舆论线](figures/35-sentiment.png)

| 模型 | L1↓ | KL↓ | 主导命中↑ | bootstrap vs 持续(95% CI) |
|---|---|---|---|---|
| **blend(0.7事件+0.3持续)** | **0.540** | **0.334** | **0.777** | **[−0.175, −0.095]** ✓ |
| 事件历史构成 | 0.527* | 0.357 | 0.747 | [−0.208, −0.088] ✓ |
| GRU 情绪头(14通道×168h,KL损失) | 0.614 | 0.382 | 0.780 | [−0.085, −0.034] ✓ |
| 圈持续(上一24h构成) | 0.674 | 0.500 | 0.772 | — |
| 马尔可夫(6×6小时转移^24) | 0.798 | 0.633 | 0.642 | [+0.030, +0.220](更差) |

(*事件基线 L1 略低于 blend 但主导命中率低 3 个点且 KL 更高;blend 在 val 上按 L1 选出
α=0.7,test 上三指标最均衡,选定。)

## 3. 技术选择解读:为什么赢的是"构成基线"而不是"演化模型"

三个否决都有明确的结构原因:

1. **马尔可夫链输给"什么都不做"**。小时级情绪转移矩阵的 24 步幂把分布推向全局稳态
   (M²⁴ 对角 [0.65, 0.16, 0.07, ...]),抹掉了事件间的构成差异——**情绪构成的方差在
   事件之间,不在小时之间的转移动力学里**。"舆论演化"在这个数据里不是一条马尔可夫链,
   是一个由事件内容锚定的常数加噪声。
2. **GRU 学到的主要还是"最近的构成"**。它显著赢持续基线(学到了平滑与全事件通道的
   参考),但追不上一个零参数的事件累计构成——168h 窗口看不到的"事件长期构成"恰好是
   最强特征。给 GRU 喂事件累计构成作为静态特征大概率能追平 blend,但一个可解释的
   两参数混合已经够用,神经方案在此没有边际(与预测线"机制模型没有边际"同构的判断)。
3. **圈层个性存在但次要**:blend 的 0.3 持续权重就是圈层个性的份额——事件定 70% 的调,
   圈层身份(枢纽圈更愤怒、机构矩阵更中性,12 号报告)修 30% 的边。

## 4. 策略接口:注入情绪 → 圈内舆论偏移

舆论线给策略层的量化接口由两半拼成,**都已经有数**:

- **传播侧**(34 号报告):注入内容的情绪改变事件的有效参数——愤怒/惊奇事件里
  权威通道 Δ 翻倍、更穿圈(cross-excitation 0.46/0.44 vs 喜悦 0.33)
- **构成侧**(本报告):圈内情绪构成 ≈ 0.7×事件构成 + 0.3×圈基线。注入 m 帖情绪 s 的
  内容并诱发 Δ 簇(其中约 77% 继承情绪 s,按转发一致率),对事件构成的推移是
  `m·(1+0.77·Δ/m)/N_event`——**注入对舆论的影响以"改变事件构成"为通道,效果与事件
  总量成反比**。在十万帖级的热点里,单点注入对圈内舆论构成的期望偏移 <1%;
  可测偏移只在小事件或组织化持续注入下发生。这个"舆论很难被单点引导,但组织化注入
  可以累积"的定量结论,同时是策略章的效果上界和风险章(圈2 类监测)的依据。

## 5. 局限

- 情绪构成 ≠ 观点立场:数据只有 6 类情绪标注,"舆论"的立场维度(支持/反对)无字段支撑,
  已在舍弃清单声明
- y24≥5 门槛使样本偏向活跃圈-事件对;沉默圈的"舆论"本身不构成有意义的预测对象
- 转发情绪 76.6% 继承率使构成预测部分反映转发结构而非独立表达;策略接口按此折扣
